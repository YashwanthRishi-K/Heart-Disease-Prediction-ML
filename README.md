# Heart Stroke Prediction Using Machine Learning

This is a machine learning mini-project completed during my college days. It implements and compares **Logistic Regression** and **Random Forest Classifier** models to predict heart stroke risks based on health metrics.

## 🚀 Features
* **Data Preprocessing:** Handles missing values and automates data type conversions.
* **Data Visualization:** Generates a correlation feature heatmap and importance tracking plots.
* **Model Optimization:** Utilizes `GridSearchCV` to automatically fine-tune the Random Forest algorithm.
* **Model Export:** Saves the final optimized training layout as a reusable `.pkl` file.

## 📊 Technologies Used
* **Language:** Python 3
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
